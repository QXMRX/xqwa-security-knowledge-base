# 安全边界

网络安全教学必须建立清晰边界。本仓库只接受合法、可控、可复现的教学内容。

## 允许的实验场景

- Docker 本地实验。
- CTF 靶场。
- 本地虚拟机。
- 明确授权的测试环境。

## 禁止的内容

- 针对公网目标的扫描、爆破、利用或攻击步骤。
- 针对真实服务器、真实网站或第三方系统的未授权测试。
- 真实 Token、Cookie、密码、API Key、SSH Key 或数据库账号。
- 未说明风险和清理方式的破坏性操作。
- 引导绕过权限、隐藏痕迹或持久化控制的内容。

## 编写实验时必须说明

- 实验目标。
- 适用对象。
- 所需环境。
- 授权边界。
- 启动步骤。
- 验证方式。
- 清理方式。
- 可能风险。

## 审核标准

审核者应确认内容是否服务于教学目标，是否限制在合法环境内，是否存在敏感信息泄露风险，是否会误导新成员攻击真实目标。

AI 可以辅助发现风险，但人工维护者必须做最终判断。
