# CTF 课程学习资源

这份清单为 32 节课程提供稳定、权威的补充阅读。课堂只要求阅读教师在当节标出的条目；其余内容用于查漏补缺，不建议一次性看完。外部练习只限平台明确提供的题目和授权环境。

## 通用基础与入门

- [picoCTF Learning Resources](https://picoctf.org/resources.html)：按 General Skills、Web、Crypto、Forensics、Binary Exploitation 和 Reversing 分类的入门指南。
- [Python 官方教程](https://docs.python.org/zh-cn/3/tutorial/)：第 3 节脚本基础的语言参考。
- [MDN HTTP 概述](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Guides/Overview)：第 4—5 节理解请求、响应与状态码。
- [Git 官方教程](https://git-scm.com/docs/gittutorial/zh_HANS-CN)：保存实验记录和 Writeup 的最小版本控制路径。

## Web 安全

- [OWASP Web Security Testing Guide 4.2](https://owasp.org/www-project-web-security-testing-guide/v42/)：测试方法、证据记录和报告结构；实践前必须确认授权范围。
- [OWASP Top 10](https://owasp.org/www-project-top-ten/)：认证、访问控制、注入和服务端输入风险的概览。
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)：参数化查询、会话管理、文件上传等防御性实现建议。

## 密码学

- [CryptoHack Introduction](https://cryptohack.org/courses/intro/course_details/)：编码、字节和 XOR 的渐进练习。
- [Cryptography I — Dan Boneh](https://www.coursera.org/learn/crypto)：现代密码学概念的系统课程。
- [NIST Cryptographic Standards and Guidelines](https://csrc.nist.gov/projects/cryptographic-standards-and-guidelines)：算法与工程实践的权威索引。

## Reverse、Pwn 与取证

- [GDB 官方文档](https://sourceware.org/gdb/documentation/)与 [Ghidra 官方文档](https://ghidra-sre.org/Documentation.html)：第 17—18 节工具参考。
- [OpenSecurityTraining2](https://p.ost2.fyi/)：体系结构、逆向和二进制安全课程；选择入门模块即可。
- [Wireshark User’s Guide](https://www.wireshark.org/docs/wsug_html_chunked/)：第 26 节离线 PCAP 分析参考。

## AI 应用安全

- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)：第 28—29 节的风险分类入口。
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)：从治理、测量与管理角度理解 AI 风险。

## 使用与维护

教师应在课前确认链接仍可访问、版本仍适用，并给出“必读 / 选读 / 练习”标记。链接失效不应阻塞课堂；主线实验必须保留本地替代材料。引用外部内容时只链接原始来源，不复制题目、Flag 或受版权保护的大段材料。
