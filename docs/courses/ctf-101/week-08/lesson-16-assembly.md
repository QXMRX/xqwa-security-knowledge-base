# 第 16 节：汇编与函数调用

> Reverse · 95 分钟 · 只掌握够用的阅读能力

## 本节目标

- 认识寄存器、内存、栈和指令指针。
- 跟踪简单函数的参数、比较和返回值。
- 将短汇编片段还原为伪代码。

## 先抓住主线

汇编不是必须逐行背诵的外语。先识别“数据从哪里来、经过什么运算、根据什么条件跳转、最后返回什么”。栈帧可以理解为一次函数调用临时使用的工作区，但真实布局由架构、编译器和优化共同决定。

## 核心概念

| 概念 | 直观作用 |
|---|---|
| 寄存器 | CPU 当前使用的少量高速状态 |
| 栈 | 支持调用、局部数据和保存状态的内存区域 |
| 比较与跳转 | 构成 `if`、循环等控制流 |
| 调用约定 | 约定参数、返回值和寄存器责任 |

## 课堂主线

1. 从一段短 C 函数预测它需要的操作。
2. 对照反汇编定位参数、比较和返回。
3. 画出两个分支的控制流。
4. 写出不追求语法完整的伪代码并运行原程序验证。

## 检查点

不要求记住全部寄存器；应能沿着一个输入找到它参与比较和影响返回值的位置。

## 可选探索

比较关闭优化与开启优化后的同一函数，观察编译器如何重排代码。

## 安全加餐：CPU 没有“变量名”

变量名主要服务源码阅读。编译后，程序依靠地址、寄存器和约定组织数据，逆向工具显示的名称常是分析者重新赋予的。

## 课后轻任务

预计 25—35 分钟：为课堂函数标注参数、关键比较、两个分支和返回值。

## 常见卡点

- 试图逐条翻译：先识别基本块和控制流。
- 混淆数值与地址：结合指令用途和内存访问判断。
- 被陌生指令卡住：先查官方指令语义，再看它是否影响主线。
