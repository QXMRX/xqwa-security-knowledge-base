# 第 2 节：Linux 与终端基础

## 本节目标

完成本节后，你应能：

1. 在终端中定位、查看和搜索文件。
2. 理解相对路径、绝对路径和文件权限的基本含义。
3. 使用管道把一个命令的输出交给另一个命令处理。

## 准备内容

- 课程提供的 Linux 虚拟机、容器或终端环境。
- 不建议在个人重要文件夹中练习删除或权限修改命令。

## 为什么值得学

终端不是“更难用的文件管理器”，而是一种把观察、筛选和重复操作组合起来的工作方式。CTF 里经常需要从一堆文件、日志或输出中找线索；命令行让这个过程可记录、可复现，也更容易交给脚本自动完成。

## 核心概念

### 路径

绝对路径从根目录开始，例如 `/work/lab`；相对路径从当前位置开始，例如 `notes/flag.txt`。可以把当前目录理解为你正在工作的实验台：相对路径描述的是从实验台到目标的位置，绝对路径描述的是从整栋楼的入口到目标的位置。

### 四个基础命令

| 命令 | 作用 | 课堂使用场景 |
|---|---|---|
| `pwd` | 显示当前位置 | 确认自己在哪个目录 |
| `ls` | 列出目录内容 | 查看题目提供了哪些文件 |
| `cat` | 输出文本文件内容 | 快速查看短文本 |
| `grep` | 搜索匹配文本 | 从日志中寻找关键词 |

### 管道

管道符 `|` 会将前一个命令的输出作为后一个命令的输入。例如先列出文件，再搜索包含 `flag` 的行。它不是魔法，而是把两个只做好一件事的小工具接起来。

## 课堂主线：从目录中找线索

在课程提供的练习目录中完成以下任务：

1. 用 `pwd` 确认当前目录。
2. 用 `ls` 查看可见文件。
3. 找出隐藏文件，并判断它们是否值得查看。
4. 使用 `grep` 在文本文件中搜索给定关键词。
5. 记录你找到线索的路径和命令。

示例命令仅用于课程练习目录：

```bash
pwd
ls -la
grep -R "flag" .
```

## 检查点

如果你能解释“我先确认位置，再列出文件，最后缩小搜索范围”，就已经掌握了终端最重要的思维方式：让每一步都有可观察的输出。

## 可选探索

尝试用 `head`、`tail` 或 `file` 查看一个陌生文件。记录它们各自回答了什么问题，不需要把所有参数背下来。

## 安全加餐：GitHub 是你的公开作品集，不是网盘

注册 GitHub 后，可以用它保存自己的学习笔记和脚本；但在提交前请确认没有 Token、Cookie、密码、真实配置文件或同学的私人信息。公开仓库一旦被索引，删除文件也不代表历史记录消失。

## 课后轻任务

预计 20—30 分钟：在课程练习环境中新建一个笔记文件，记录本节用到的 4 个命令和各自的用途。可选地，把不含敏感内容的笔记提交到自己的 GitHub 仓库。

## 常见卡点

- 找不到文件：先运行 `pwd`，再确认相对路径是相对于哪里。
- `grep` 输出太多：先限定一个目录或更具体的关键词。
- 权限被拒绝：不要急着使用高权限命令，先确认目标文件是否属于课程环境。
