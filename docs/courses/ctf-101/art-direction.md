# CTF 课程视觉与内容标准

## 主题：Signal / Trace

本课程采用“从杂乱信号中找到可验证线索”的视觉与叙事主题。它应呈现为克制、现代的数字实验室：有技术感，但不使用刻板的满屏绿色代码、故障特效或电影式入侵画面。

## 色彩与字体

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 | `#0B1020` | 深蓝黑，适合投影和夜间阅读 |
| 主文字 | `#E6EDF7` | 高对比度冷白 |
| 主强调 | `#48C6EF` | 用于关键概念、链接和进度 |
| 次强调 | `#F4B942` | 用于提示、检查点和可选探索 |
| 风险提示 | `#F26B6B` | 只用于安全边界或错误提示 |
| 辅助文字 | `#AAB7CF` | 用于注释和次要信息 |

字体优先使用 `Inter` 与 `Noto Sans SC`，并提供系统无衬线字体回退。正文最小字号为 20 px，代码最小字号为 18 px。

## Reveal.js 课件规范

- 每份课件控制在 18—28 页；本阶段的试讲课件可为 12—16 页。
- 一页只传达一个核心结论；代码页不超过 12 行。
- 页面固定包含课次、模块和进度标记，方便学生在中途加入或复盘。
- 常用页面类型为问题引入、概念拆解、动手检查点、流程图、代码演示、安全加餐和收束页。
- 动画只用于逐步揭示推理过程，不使用自动播放、闪烁或干扰阅读的特效。
- 图示优先使用 CSS、SVG 或可访问的流程图；避免为装饰加入与知识无关的图片。

课件当前使用固定版本的 Reveal.js `5.1.0` CDN。正式线下授课前可将同版本资源镜像到 `docs/slides/ctf-101/vendor/`，以支持无外网环境。

## 讲义表达规范

每节讲义固定包含：本节目标、准备内容、核心概念、课堂主线、检查点、可选探索、安全加餐、课后轻任务、常见卡点和延伸资料。

- 先描述问题和可观察的现象，再介绍原理，最后完成验证。
- 比喻只用于建立直觉，紧接着给出精确的技术定义。
- 使用“可以尝试”“如果时间允许”等措辞；不以打卡、排名或羞耻感驱动学习。
- 练习区分“课堂主线”和“可选探索”。主线可在课堂中完成；探索不完成不扣分。
- 解答展示推理过程、工具选择和失败路径，不只给 Flag 或最终命令。

## 任务负担标准

| 类型 | 建议耗时 | 要求 |
|---|---:|---|
| 课堂主线 | 课堂内 | 完成最低可行实验 |
| 课后轻任务 | 20—40 分钟 | 建议完成，可补交 |
| 可选探索 | 30—90 分钟 | 完全自愿 |
| 分享记录 | 10 分钟 | 自愿，可记录问题或踩坑 |

课程不以连续刷题、公开排名或每周强制提交作为评价方式。学生提交“已尝试的方法、卡住的位置和下一步猜想”同样是有效学习记录。
