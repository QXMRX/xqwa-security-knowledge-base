# 第 11 节：编码、加密与哈希

> Crypto · 95 分钟 · 概念分界课

## 本节目标

- 区分编码、加密和哈希的目的。
- 根据输入输出特征选择第一步验证方法。
- 使用 Python 完成常见表示转换。

## 先抓住主线

三者都可能把可读文本变成看不懂的字符串，但目标不同：编码为了表示和传输，加密为了在密钥控制下保密，哈希为了得到固定长度摘要。外观相似不能替代机制判断。

## 核心概念

| 类型 | 是否需要密钥 | 是否设计为可逆 | 典型用途 |
|---|---|---|---|
| 编码 | 否 | 是 | 表示与传输 |
| 加密 | 是 | 持有正确密钥时可逆 | 保密通信 |
| 哈希 | 否 | 不是为还原设计 | 完整性和密码验证 |

## 课堂主线

1. 观察四组不同格式的数据。
2. 从字符集、长度和上下文提出类型猜想。
3. 使用本地工具验证编码，不以在线工具上传未知数据。
4. 记录错误猜想为什么被排除。

## 检查点

你应能解释：Base64 能还原原文，因此不能为敏感信息提供保密性。

## 可选探索

给 Python 转换脚本增加十六进制、Base64 与字节数组三种视图。

## 安全加餐：密码管理器为什么有用

密码管理器的价值是帮助每个站点使用独立、随机的密码；它不能替代双因素认证和设备安全，但能显著减少密码复用。

## 课后轻任务

预计 20 分钟：制作一张三栏对照卡，分别写出编码、加密、哈希“解决什么”和“不能解决什么”。

## 常见卡点

- 看到长字符串就判断为哈希：先看长度、字符集和上下文。
- 把“不可读”当“安全”：可读性不是安全性质。
- 上传未知题目文件到在线工具：优先使用本地环境。
