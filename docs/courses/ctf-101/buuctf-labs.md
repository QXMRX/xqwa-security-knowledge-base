# BUUCTF 优先实验题单

## 当前平台状态

[BUUCTF 官网](https://buuoj.cn/)当前明确标注已进入归档模式，并建议使用 [DASCTF 新平台](https://ctf2.dasctf.com/)。BUUCTF 挑战列表需要登录后查看，因此本页的题名是历史题库候选，不代表当天一定能够创建实例。

本课程仍按“BUUCTF 已有题优先”选题，但教师必须在授课前完成可用性复核。不得把平台账号、动态靶机地址、Flag 或下载附件提交到仓库。

## 使用流程

1. 教师登录 BUUCTF，在对应分类中按本页题名搜索。
2. 确认题目仍可打开、附件可下载、实例能启动且难度适合新生。
3. 在下方检查表记录日期和结果，不记录账号或 Flag。
4. 课堂发布题名与平台固定入口，由学生使用自己的账号。
5. BUUCTF 不可用时，依次切换到 DASCTF 同知识点题、仓库离线实验。

## 按课次选题

“候选题”优先选择左侧第一题。题名不存在、难度变化或环境失效时，不要临时换成更高风险的公网目标。
