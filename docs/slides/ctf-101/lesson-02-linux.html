Linux 与终端基础

终端不是更难用的文件管理器；它是一种可以观察、组合和复现操作的工作方式。

今天能带走什么

三个目标

定位知道自己在哪个目录
观察查看文件并缩小搜索范围
组合用管道连接小工具

实验选择

BUUCTF 已有题优先

使用课前已核验的 Basic / Linux Labs；归档题不可用时，切换仓库离线练习目录。

只在平台题目与附件的授权范围内操作。

一个准确的直觉

当前目录像你的实验台

相对路径描述“从实验台走到哪里”；绝对路径从系统根目录开始描述完整位置。它们都是路径，只是参照点不同。

四个基础命令

先让每一步都有输出

pwd我现在在哪？
ls这里有什么？
cat短文本写了什么？
grep哪里出现了关键词？

工具组合

管道不是魔法

每个命令只做一件小事。管道 | 把前一个命令的输出交给下一个命令处理，让你逐步缩小问题。

列出内容→筛选关键词→检查线索

课堂主线

从练习目录中找线索

pwd
ls -la
grep -R "flag" .

优先在课前核验的 BUUCTF Linux Labs 中练习；平台不可用时使用讲义明确创建的本地目录。每执行一步，都先看输出。

检查点

你能解释这条路径吗？

“我先确认位置，再列出文件，最后缩小搜索范围。”
这就是终端最重要的思维方式。

可选探索

让陌生文件先开口

试试 file、head 或 tail。不用背参数，只要记录：这个工具回答了我什么问题？

安全加餐

GitHub 是作品集，不是网盘

  • 可以保存学习笔记和无敏感内容的脚本。
  • 提交前确认没有 Token、Cookie、密码或真实配置。
  • 公开历史可能长期可见，删除文件不等于抹去记录。

记录 pwd、ls、cat、grep 各自解决什么问题。时间不够时，先完成课堂记录。
